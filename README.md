# Flappy Bird

A single-player Flappy Bird-style game built with Java Swing. Use **Up** or
**Space** to flap, **Left/Right** to steer, and **Down** to dive. The score is
displayed at the top center of the window. Press **Enter** or **R** to restart
after a game over.

## Run

From the repository root, compile and launch with a JDK:

```powershell
javac -d target src/FlappyBirdGame.java
java -cp target FlappyBirdGame
```

Press **Up** or **Space** to start a new game.
