# Instructions for agents working in this repository

This repository starts empty on purpose. The person you work with decides what gets built. Your job is to build it inside the structure that is already here.

## How work flows here

1. Create a branch for every change. Never commit to `main`.
2. Write source code in the `src/` directory.  When compiling code, place the output in the `target/` directory.
3. Open a pull request and give the person a link to the pull request. Do not merge it yourself.
